# Rojoblox

**Rojoblox** is a classic Roblox revival project created by **@poulet**, following in the footsteps of **Opliux**, but with an emphasis on clean, maintainable code, original design, and avoiding low-quality AI-generated slop.

Rojoblox aims to recreate the nostalgic classic Roblox experience while introducing modern improvements, custom features, and a completely unique identity.

## Tech Stack

Built using the following languages, frameworks, and technologies:

<img src="https://skillicons.dev/icons?i=cs,dotnet,react,ts,html,css&theme=dark" alt="C#, .NET, React, TypeScript, HTML, CSS" />

- **Backend:** C# / ASP.NET Core / .NET
- **Frontend:** React / TypeScript / HTML / CSS
- **Database:** Entity Framework Core
- **Avatar Rendering:** RCCService

## Platform Support

Rojoblox currently supports or plans to support:

- **Windows**
- **Linux**
- **macOS**
- **iOS**
- **Android**

Cross-platform compatibility is one of the project's long-term goals, allowing users to experience classic Roblox across a variety of devices.

## Client Compatibility

Rojoblox currently focuses on the **2016 Roblox client** to ensure compatibility and provide a consistent experience.

However, **multi-year support is not off the table.**

Support for additional classic Roblox eras is being considered, with **2013** being a potential future addition.

## Features

- **Original Website Design:** A completely custom design language with unique components, layouts, and styling rather than a direct recreation of the original Roblox website.
- **My Themes:** Personalized website themes that allow users to customize their experience.
- **Avatar Editor:** Customize your avatar's appearance, body colors, and eventually equipped items and outfits.
- **Catalog:** Browse classic Roblox-inspired virtual items and customize your character.
- **Games:** Discover and explore user-created experiences through a dedicated game discovery system.
- **User Profiles:** Personalized profiles featuring user information, descriptions, and creations.
- **Cross-Platform Support:** Planned compatibility across desktop and mobile operating systems.
- **Multi-Year Potential:** The possibility of supporting multiple classic Roblox client versions in the future.

Some features are still in development and may not be available immediately.

## Development Status

**Rojoblox is currently in active development and has not been publicly released.**

The project is planned to launch privately before any potential wider availability. Development focuses on stability, compatibility, performance, and delivering a polished experience rather than rushing a release.

A public website URL is not available yet because domains and hosting cost money (and I'm broke), but one is planned soon.
